# Complex Hypospadias – SCHN DSD Referral Checklist (iPhone web app)

Fill in the referral checklist on an iPhone and email it from a NSW Health account.

**Install:** open the GitHub Pages link in Safari → Share → Add to Home Screen.

- No patient data is stored or sent anywhere by the app; the email is composed in the phone's own Mail/Outlook app.
- Only the "send to" address and the "documented by" name are remembered, on the device.
